Mentions légales

Flexarion est un studio fictif. Ce site a été conçu et développé dans le cadre d’un concours du BUT Informatique d’Aix-en-Provence.

Un projet pédagogique

Le studio Flexarion, le jeu Maestral, les membres de l’équipe, les chiffres et les événements présentés sur ce site sont imaginaires. Toute ressemblance avec des personnes ou des entreprises existantes serait fortuite.

Éditeur du site

Site conçu, rédigé et développé par Jean Damez, Wanis Said Boutabouzi, Rayan Keokham et Aymen El Mestari, étudiants en BUT Informatique à l’IUT d’Aix-Marseille, site d’Aix-en-Provence.
Contact : flexarioncontact@gmail.com

Hébergement

GitHub Pages — GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, États-Unis.

Propriété intellectuelle

Les textes, le code et les illustrations de ce site ont été créés pour ce projet. Les polices Syne, Manrope et JetBrains Mono sont distribuées sous licence libre (SIL Open Font License).

Données personnelles et cookies

Ce site ne dépose aucun cookie et n’utilise aucun outil de mesure d’audience. Le formulaire de contact n’enregistre rien : il prépare simplement un message dans votre propre logiciel de messagerie.

Les polices de caractères sont chargées depuis le service Google Fonts, ce qui implique une requête vers les serveurs de Google lors de votre visite.
